Fraud Seeker – DeepDetect is a frontend web application designed to assist in fraud detection. Built using modern web technologies, it offers a responsive and visually appealing UI that can be integrated with backend models or APIs for real-time fraud analysis.

🚀 Tech Stack
React (via Vite)

TypeScript

Tailwind CSS

shadcn/ui components

📦 Features
Clean, modular frontend codebase

Easy to customize and extend

Ready for integration with ML models or detection services
